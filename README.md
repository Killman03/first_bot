# Zoom Clipboard Watcher

Небольшая программа для Windows: после копирования корректной ссылки на
Zoom-встречу она автоматически открывает её через стандартный обработчик Windows.
Сторонние Python-пакеты не нужны.

## Запуск

1. Дважды щёлкните `run_zoom_watcher.bat`.
2. Не закрывайте появившееся окно консоли.
3. В Telegram выберите **Копировать ссылку** у сообщения с Zoom-встречей.
4. Дождитесь открытия Zoom и после входа нажмите `Alt+Y`, чтобы поднять руку.

Ссылка, уже открытая в последние 15 секунд, повторно не запускается. Скрипт
принимает только `http`/`https`-ссылки формата встречи на доменах `zoom.us` и
`zoom.com` (включая их поддомены). Адреса наподобие `zoom.us.example.com`
отклоняются.

При старте содержимое буфера не открывается: программа реагирует только на новые
операции копирования. Остановить её можно сочетанием `Ctrl+C` или закрытием окна.
